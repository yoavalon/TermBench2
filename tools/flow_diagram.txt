    loop Per Target Behavior & Length
        Gen->>LLM: Prompt domain & structural constraints

        Gen->>Gen: Extract AST skeleton & reject collisions
        Gen->>Sandbox: Dispatch for untrusted execution
        Sandbox-->>Gen: Return status (Timeout, RecursionError, Success)

    end

        Trans->>FS: Load source .py and target behavior label

        Trans->>LLM: Prompt behavior-preserving translation
        LLM-->>Trans: Return formatted polyglot code
        Trans->>Trans: Enforce language formatting (e.g., Java class names)
        Trans->>FS: Commit target language file
